# 🕒 Time Tracer

**Time Tracer** is a full-stack productivity web application built using the MERN (MongoDB, Express, React, Node.js) stack. It helps users track their daily routines, manage their events and tasks, and provides a summary of their productivity. This project is ideal for students, professionals, or anyone looking to optimize their time.

---

## ⚙️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (via Mongoose)
- **Authentication**: JWT (via cookies)
- **File Uploads**: Cloudinary
- **Form Handling**: React Hook Form
- **Routing**: React Router Dom
